श्री जगन्नाथ सहकारी दूध संस्था - ऑफलाइन वेब अ‍ॅप

फोल्डरमधील फाइल्स HTTPS असलेल्या वेब होस्टिंगवर (उदा. GitHub Pages / Netlify) अपलोड करा.
नंतर Android Chrome मध्ये त्या HTTPS लिंक उघडा > ⋮ मेनू > Add to Home screen / Install app.
एकदा अ‍ॅप उघडल्यानंतर फाइल्स कॅश झाल्यावर इंटरनेटशिवाय चालेल.

महत्त्वाचे:
- पहिल्यांदा इंस्टॉल/कॅश करण्यासाठी इंटरनेट आणि HTTPS लिंक आवश्यक आहे.
- नोंदी या त्या मोबाईलच्या Chrome/App storage मध्येच राहतात.
- फोनचा डेटा/ब्राउझर डेटा पुसल्यास नोंदी जाऊ शकतात; नियमितपणे Backup घ्या.
- FAT/SNF दर सध्या हाताने भरायचा आहे; पूर्ण दरतक्ता स्वयंचलित जोडलेला नाही.
- हा पहिला प्रोटोटाइप आहे; अधिकृत लेखा/कर/कायदेशीर सॉफ्टवेअर म्हणून वापरण्यापूर्वी तपासणी करा.
